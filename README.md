# Filipe Meltzer — Architecture Portfolio

The digital portfolio of Filipe Meltzer, Architect & Urbanist.
A static website (HTML, CSS and plain JavaScript, no build step) published with GitHub Pages.

**Live site:** https://filipeidea.github.io/Portfolio/

## Structure

```
index.html          Home: introduction, featured images, selected projects
project.html        One page per project, chosen by ?p=<slug> (e.g. project.html?p=monolyt)
sketchbook.html     Freehand sketches and design process
profile.html        Biography, experience, awards, publications, places, skills
resume.html         Concise, print-friendly résumé + CV download
404.html            Not-found page
assets/
  data/projects.js  ← ALL PROJECT CONTENT AND CONTACT DETAILS (edit this)
  data/images.js    Image sizes, generated by tools/build_images.py (do not edit)
  img/<project>/    Optimised WebP images in several widths
  docs/             Downloadable CV (PDF)
  css/style.css     All styling (colours and fonts are variables at the top)
  js/app.js         Header, footer, project pages, filters, image viewer
tools/build_images.py  Turns original images into optimised WebP files
```

## Edit content

Everything about the projects lives in `assets/data/projects.js`:

- **Edit a project:** change its text fields (title, location, area, stages, description…).
  Leave a field as `null` to hide it.
- **Reorder projects:** move the blocks; the order there is the order on the home page.
- **Add a project:** copy an existing block, give it a new `slug`, and point
  `cover` and `gallery` at image keys that exist (see below).
- **Contact:** at the bottom of the same file, `SITE.email` is `null` (hidden).
  Put your email address there to show it on the site.

Sketchbook, profile and résumé text is written directly in `sketchbook.html`,
`profile.html` and `resume.html`.

## Add images

1. Add a line to `MANIFEST` in `tools/build_images.py`, e.g.
   `"new-project/facade": ("S", "folder/original-file.jpg"),`
   (`S` = path inside your source portfolio folder, `C` = path inside a folder of prepared crops).
2. Run (Python 3 with Pillow: `pip install pillow`):
   ```
   python3 tools/build_images.py "<source portfolio folder>" "<crops folder>"
   ```
   This writes `assets/img/new-project/facade-640.webp`, `-1280.webp`, `-2000.webp`
   and updates `assets/data/images.js`.
3. Use `"new-project/facade"` as an image key in `projects.js`.

## Preview locally

```
python3 -m http.server 8000
```
then open http://localhost:8000. (Opening the HTML files directly also works in most browsers.)

## Publish

The site is deployed by GitHub Actions (`.github/workflows/pages.yml`) on every push to `main`.
In the repository settings, **Settings → Pages → Source** must be set to **GitHub Actions**.
All paths are relative, so the site works at `/Portfolio/` or on a custom domain
(if you add a custom domain, update the `<base href>` in `404.html`).

## Image rights

Project images for Architects Office projects are the property of the office and its clients.
Only images already officially published, or approved by the office, should be shown here.
